# Forma — React Hero Website

A responsive, animated landing page inspired by the reference layout. Built with React, Vite, CSS, and Lucide icons.

## Run it on your computer

1. Install **Node.js LTS** from the official Node.js website: https://nodejs.org/
2. Extract this ZIP file.
3. Open the extracted `react_hero_website` folder in VS Code.
4. Open Terminal inside VS Code and run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Customize

- Edit text and sections in `src/App.jsx`.
- Change colors, spacing, and responsive styling in `src/styles.css`.
- Update the browser title in `index.html`.

The contact buttons currently show demo toast messages; connect them to a real contact form or email service when you are ready.
